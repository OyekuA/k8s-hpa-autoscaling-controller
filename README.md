# k8s-hpa-autoscaling-controller

A hands-on Kubernetes project demonstrating Horizontal Pod Autoscaling (HPA). This project deploys a CPU-intensive FastAPI microservice on a local kind cluster and configures an HPA controller to scale its pods based on CPU utilization collected by Metrics Server, under synthetic load generated by Locust. Prometheus provides read-only observability of the scaling behavior.

## Limitations

Single-node kind demo: local-only, no production hardening, no resource limits, no persistent storage (Prometheus holds data in memory for the session). Scaling behavior depends on host CPU speed; the FastAPI service is CPU-bound by design. The three most common failure modes of the metrics pipeline are diagnosed in [TROUBLESHOOTING.md](TROUBLESHOOTING.md).
